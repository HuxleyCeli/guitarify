# Guitarify

App web para guitarra, instalable en el teléfono: **afinador**, **reconocedor de
notas y acordes** en vivo, y **acordes de una canción** en orden.

Funciona sin servidor y sin internet (después de abrirla una vez). Hecha con
HTML, CSS y JavaScript, sin librerías.

Proyecto del Bachillerato Internacional.
